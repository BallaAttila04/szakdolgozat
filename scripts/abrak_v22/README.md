# A dolgozat ábráinak v22-es változata (legalább 10 pontos feliratok)

Az útmutató szerint az ábrákon is legalább 10 pontos betű kell. A `min10.py` futtató minden
`savefig` előtt a feliratokat a dolgozatbeli 6,0 hüvelykes megjelenítési szélességre vetítve
legalább 10,3 pontra emeli, és kiírja a legkisebb tényleges méretet.

Használat (példa): `python min10.py adatkorok_abra.py --ki adatkorok.png`

| Ábra | Szkript |
|---|---|
| 1., 2., 8. | uj_abrak_v9.py |
| 3., 6. | ket_uj.py |
| 4., 9., 10., 11. | negy.py (abrak_v7.py függvényei) |
| 5. | adatkorok_abra.py (új alfejezetszámokkal) |
| 7. | skala_abra.py (outputs/skalazas.csv) |
| 12., 13. | hormuz_abrak11.py (hormuz_elemzes.py függvényei) |
